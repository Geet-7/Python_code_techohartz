Comparison Operators

📖 Usage:

Logical Operators

📖 Short-Circuit Evaluation:

Python uses short-circuit evaluation: in a and b, if a is False, b is never evaluated. In a or b, if a is True, b is skipped. This can improve performance.

Operators

  • and - Both must be True
  • or - At least one True
  • not - Inverts the value

Examples

x, y = True, False
print(x and y)  # False
print(x or y)   # True
print(not x)    # False

# Practical example
age = 25

print(age > 18 and not is_student)

  • *= Multiply and assign

Strings

String Operations

📖 String Manipulation:

Strings support + (concatenation) to join them and * (repetition) to repeat them. The in operator checks if a substring exists within a string - very useful for searching.

# Concatenation
first = "Hello"
second = "World"
result = first + " " + second  # "Hello World"

# Repetition
repeated = "Ha" * 3  # "HaHaHa"

# Length
print(len("Python"))  # 6

# Membership
print("Py" in "Python")  # True
Strings

String Methods

📖 Method Chaining:

String methods return NEW strings (strings are immutable). You can chain methods: text.strip().upper() first removes whitespace, then converts to uppercase. This is a common Python pattern.

Common Methods

  • upper() - Uppercase
  • lower() - Lowercase
  • title() - Title Case
  • strip() - Remove whitespace
  • replace() - Replace text

Examples

text = "  Hello World  "
print(text.upper())     # "  HELLO WORLD  "
print(text.strip())     # "Hello World"
print(text.replace("World", "Python"))
Strings

String Formatting

📖 f-strings Are Best:

f-strings (formatted string literals) were introduced in Python 3.6 and are now the preferred way to format strings. They're more readable and faster than older methods. Use {variable:.2f} to format numbers to 2 decimal places.

# f-strings (recommended)
name = "Alice"
age = 25
print(f"Name: {name}, Age: {age}")

# format() method
print("Name: {}, Age: {}".format(name, age))

# Percentage formatting (old style)
print("Name: %s, Age: %d" % (name, age))

# Formatting numbers
pi = 3.14159
print(f"Pi: {pi:.2f}")  # Pi: 3.14
Strings

String Slicing

📖 Slice Syntax:

The syntax is [start:stop:step]. Start is inclusive, stop is exclusive. Negative indices count from the end. [::-1] is a common trick to reverse a string.

text = "Python"

# Basic slicing
print(text[0:2])    # "Py"
print(text[2:5])    # "tho"
print(text[:3])     # "Pyt"
print(text[3:])     # "hon"

# Negative indexing
print(text[-2:])    # "on"
print(text[:-2])    # "Pyth"

# Step
print(text[::2])    # "Pto"
print(text[::-1])   # "nohtyP" (reverse)
Collections

Lists

📖 List Characteristics:

Lists are the most versatile Python collection. They're ordered (items have a position), mutable (can be changed), and allow duplicates. Use lists when you need a sequence of items that may change.

Definition: Ordered, mutable collection of items.

# Creating lists
fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]

# Empty list
empty = []
empty = list()
Lists

List Indexing and Slicing

📖 Zero-Based Indexing:

Python uses zero-based indexing - the first element is at index 0. Negative indices count from the end (-1 is the last element). Slicing works exactly like string slicing.

fruits = ["apple", "banana", "cherry", "date"]

# Indexing
print(fruits[0])     # "apple"
print(fruits[-1])    # "date"

# Slicing
print(fruits[1:3])   # ["banana", "cherry"]
print(fruits[:2])    # ["apple", "banana"]
print(fruits[::2])   # ["apple", "cherry"]
Lists

Adding Elements to Lists

📖 Method Differences:

append() adds one item to the end. insert() adds at a specific position. extend() adds multiple items from another iterable. Choose based on where and how many items you need to add.

fruits = ["apple", "banana"]

# append() - add to end
fruits.append("cherry")
# ["apple", "banana", "cherry"]

# insert() - add at position
fruits.insert(1, "blueberry")
# ["apple", "blueberry", "banana", "cherry"]

# extend() - add multiple
fruits.extend(["date", "elderberry"])
Lists

Removing Elements from Lists

📖 Remove vs Pop vs Del:

remove() removes by value (first occurrence). pop() removes by index and returns the removed item. del deletes by index without returning. clear() empties the entire list.

fruits = ["apple", "banana", "cherry", "date"]

# remove() - by value
fruits.remove("banana")

# pop() - by index (default last)
last = fruits.pop()        # removes "date"
first = fruits.pop(0)      # removes "apple"

# del - delete by index
del fruits[0]

# clear() - remove all
fruits.clear()
Lists

List Methods

📖 In-Place vs Return:

sort() and reverse() modify the list in-place and return None. If you need a sorted copy without modifying the original, use sorted(list) instead.

Common Methods

  • sort() - Sort in place
  • reverse() - Reverse in place
  • index() - Find index
  • count() - Count occurrences
  • copy() - Copy list

Examples

nums = [3, 1, 4, 1, 5]
nums.sort()           # [1, 1, 3, 4, 5]
nums.reverse()        # [5, 4, 3, 1, 1]
print(nums.index(4))  # 1
print(nums.count(1))  # 2
Collections

Tuples

📖 Why Tuples?:

Tuples are like lists but immutable - once created, they cannot be changed. This makes them safer for data that shouldn't change (like coordinates, database records). They're also slightly faster than lists.

Definition: Ordered, immutable collection of items.

# Creating tuples
coordinates = (10, 20)
person = ("Alice", 25, "Engineer")

# Single element tuple (note comma)
single = (5,)

# Accessing elements
print(coordinates[0])   # 10
print(person[1])        # 25

# Tuples are immutable
# coordinates[0] = 30  # Error!
Tuples

Tuple Operations

📖 Tuple Unpacking:

Tuple unpacking lets you assign multiple variables at once: x, y = (10, 20). This is incredibly useful for swapping values (a, b = b, a) and returning multiple values from functions.

# Concatenation
t1 = (1, 2)
t2 = (3, 4)
t3 = t1 + t2        # (1, 2, 3, 4)

# Repetition
print(t1 * 2)       # (1, 2, 1, 2)

# Membership
print(2 in t1)      # True

# Unpacking
x, y = (10, 20)
print(x)            # 10
print(y)            # 20
Collections

Sets

📖 Set Use Cases:

Sets automatically remove duplicates and are optimized for membership testing (in operator). Use sets when you need unique values or want to perform mathematical set operations like union and intersection.

Definition: Unordered collection of unique items.

# Creating sets
fruits = {"apple", "banana", "cherry"}
numbers = {1, 2, 3, 3, 3}  # {1, 2, 3}

# Empty set
empty = set()  # Not {} (that's dict)

# Adding elements
fruits.add("date")

# Removing elements
fruits.remove("banana")
fruits.discard("elderberry")  # No error if missing
Sets

Set Operations

📖 Math-Like Operations:

Sets support mathematical operations: union (all items), intersection (common items), difference (items in A but not B), and symmetric difference (items in either but not both).

A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

# Union
print(A | B)        # {1, 2, 3, 4, 5, 6}

# Intersection
print(A & B)        # {3, 4}

# Difference
print(A - B)        # {1, 2}

# Symmetric Difference
print(A ^ B)        # {1, 2, 5, 6}
Collections

Dictionaries

📖 Key-Value Pairs:

Dictionaries map keys to values, like a real dictionary maps words to definitions. Keys must be unique and immutable (strings, numbers, tuples). Values can be anything. Dictionaries are the backbone of Python's object system.

Definition: Key-value pairs for storing data.

# Creating dictionaries
person = {
    "name": "Alice",
    "age": 25,
    "city": "New York"
}

# Accessing values
print(person["name"])       # "Alice"
print(person.get("age"))    # 25
print(person.get("salary", 0))  # 0 (default)
Dictionaries

Dictionary Methods

📖 Safe Access:

Use get() instead of bracket notation when you're not sure if a key exists - it returns None (or a default) instead of crashing. keys(), values(), and items() are essential for iteration.

person = {"name": "Alice", "age": 25}

# keys(), values(), items()
print(person.keys())    # dict_keys(['name', 'age'])
print(person.values())  # dict_values(['Alice', 25])
print(person.items())   # dict_items([('name', 'Alice'), ...])

# update()
person.update({"city": "NYC"})

# pop()
name = person.pop("name")
Collections

Iterating Over Collections

📖 For Loop Patterns:

Lists iterate over values. Dictionaries iterate over keys by default; use .items() for key-value pairs. Sets iterate in arbitrary order (no guaranteed order). The for loop is the standard way to process collections.

# List iteration
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# Dictionary iteration
person = {"name": "Alice", "age": 25}
for key, value in person.items():
    print(f"{key}: {value}")

# Set iteration
for item in {1, 2, 3}:
    print(item)
Collections

Membership Testing

📖 Performance Note:

Membership testing (in) is O(1) for sets and dictionaries (very fast), but O(n) for lists and tuples (slower for large collections). For dictionaries, in checks keys, not values.

# in operator
fruits = ["apple", "banana"]
print("apple" in fruits)    # True
print("grape" in fruits)    # False

# Dictionary keys
person = {"name": "Alice"}
print("name" in person)     # True
print("Alice" in person)    # False (checks keys)

# Set membership
print(3 in {1, 2, 3})       # True

Control Flow

If Statement

📖 Decision Making:

The if statement is the most basic form of control flow. The indented code block only runs if the condition evaluates to True. The else clause handles the False case.

Definition: Executes code only if a condition is True.

age = 18

if age >= 18:
    print("You are an adult.")

# With else
if age >= 18:
    print("Adult")
else:
    print("Minor")
Control Flow

Elif Statement

📖 Multiple Conditions:

elif (else if) lets you check multiple conditions in sequence. Only the first True condition's block executes. The final else is optional and catches everything that didn't match.

score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Grade: {grade}")
Control Flow

Nested Conditions

📖 When to Nest:

Nested conditions check sub-conditions within a condition. While powerful, deep nesting can make code hard to read. Consider combining conditions with and/or or using early returns in functions instead.

age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed.")
    else:
        print("ID required.")
else:
    print("Too young.")
Control Flow

Match Case (Python 3.10+)

📖 Pattern Matching:

match-case is Python's version of switch-case statements. It's more powerful than if-elif chains for matching specific values or patterns. The _ case is the default (wildcard) that matches anything.

day = "Monday"

match day:
    case "Monday":
        print("Start of week")
    case "Friday":
        print("End of week")
    case "Saturday" | "Sunday":
        print("Weekend")
    case _:
        print("Midweek")
Loops

For Loop

📖 Iteration:

Python's for loop iterates over any iterable (list, string, tuple, set, dict, etc.). Unlike other languages, Python's for loop works like a "for each" - it directly gives you each item, not an index.

Types of Errors

📖 Syntax vs Runtime:

Try and Except

📖 Specific vs General:

Catch specific exceptions first, then general ones. A bare except: catches everything (including system exits) and is usually a bad idea. Always specify which exception types you expect.

    print("Cannot divide by zero.")
except Exception as e:
    print(f"An error occurred: {e}")

except FileNotFoundError:
    print("File not found.")
else:

    print(content)
finally:
    # Always runs
    print("Cleanup complete.")
    file.close()

📖 Base Case is Critical:

Iterators

📖 Iterator Protocol:

An iterator is an object that implements __iter__() and __next__(). It produces values one at a time and raises StopIteration when exhausted. This is the foundation of Python's for-loop.

# Using iter() and next()

print(next(iterator))  # 3
# next(iterator) raises StopIteration

# Custom iterator
class CountDown:
    def __init__(self, start):
        self.start = start
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.start <= 0:
            raise StopIteration
        self.start -= 1
        return self.start + 1

Generators

📖 Memory Efficiency:

        count += 1

# Usage

# Memory efficient!

Encapsulation

📖 Access Control:

Python uses naming conventions: _protected (single underscore) means "use at your own risk," __private (double underscore) triggers name mangling. Python trusts developers - nothing is truly private.

Definition: Bundling data and methods that work on that data.

class BankAccount:

        self.__pin = 1234  # Private

Inheritance

📖 IS-A Relationship:

Inheritance models "IS-A" relationships. A Dog IS an Animal, so Dog inherits from Animal. The child class can override methods to provide specialized behavior while reusing common functionality.

class Animal:
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return f"{self.name} says woof!"

class Cat(Animal):
    def speak(self):
        return f"{self.name} says meow!"

dog = Dog("Buddy")
print(dog.speak())  # Buddy says woof!
OOP

Polymorphism

📖 Same Interface, Different Behavior:

Polymorphism lets different classes implement the same method name in their own way. You can write code that works with any object that has a certain method, regardless of its specific class.

# Same interface, different behavior
class Shape:
    def area(self):
        pass

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return 3.14159 * self.radius ** 2

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height
OOP

Abstraction

📖 Abstract Base Classes:

ABCs define a contract - any subclass MUST implement the abstract methods. This ensures consistency across different implementations. You can't instantiate an abstract class directly.

from abc import ABC, abstractmethod

class Vehicle(ABC):
    @abstractmethod
    def start(self):
        pass
    
    @abstractmethod
    def stop(self):
        pass

class Car(Vehicle):
    def start(self):
        print("Car starting...")
    
    def stop(self):
        print("Car stopping...")
OOP

Class and Static Methods

📖 Method Types:

@classmethod receives the class as first argument (cls) - used for factory methods. @staticmethod receives neither instance nor class - used for utility functions that belong to the class namespace.

class Person:
    count = 0
    
    def __init__(self, name):
        self.name = name
        Person.count += 1
    
    @classmethod
    def get_count(cls):
        return cls.count
    
    @staticmethod
    def is_adult(age):
        return age >= 18

print(Person.get_count())
print(Person.is_adult(20))

📖 Vectorization:
